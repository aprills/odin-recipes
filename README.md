# odin-recipes

Learnt about html elements and made a basic website which consists of three different recipes

Main Learning - 
I treated index.html as if it were the odin-recipes folder, and thought ../ would step "out of the file into the folder." But index.html is already sitting inside odin-recipes/ — so ./ is what refers to that folder, not ../. 
../ instead steps one level above odin-recipes, out of your project.
